# gid (generate id)

A CLI tool to generate unique identifiers.

## Examples

### Generating a UUID

```bash
gid uuid

> 0cadfc7c-1af9-45c9-a22c-6bf24f8bdec1
```

### Generating a ULID

```bash
gid ulid

> 01KB0X8GVBZVM7QBSW3RT7AJ70
```

## Supported identifiers

- uuid
- ulid
- ksuid
